# src/ — mã nguồn dùng chung

Chỉ còn một gói: [`healthsense_ml/`](healthsense_ml/README.md), thư viện lọc tín hiệu, dò nhịp và tính 16 đặc trưng HRV mà mọi thí nghiệm và AI-Service cùng dùng. Thứ tự đọc 9 module nằm trong README của gói.

Bảo tàng phiên bản v1–v4 (`src/v1..v4`, `src/vlab`, `src/report`) đã được gỡ khỏi repo để tránh trùng lặp; lịch sử của chúng vẫn nằm trong git, phần kể chuyện về data leakage của các đời đầu xem mục 3 của README gốc.
