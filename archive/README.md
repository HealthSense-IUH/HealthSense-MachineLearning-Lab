# Archive

Earlier model versions, kept for history. They are not used by the published model.

- `v4/`: pooled single-domain baseline with subject-level evaluation (notebooks, results, model).
- `v5/`: frozen single-domain model with external validation (notebooks, scripts, model card). The V5 extractors that V6 still uses are in `1_prepare_data/scripts/v5_extractors/`.

See `docs/HISTORY_vi.md` for the V4 → V5 → V6 story.
