# reports/ — sản phẩm để công bố

| Thư mục | Nội dung |
|---|---|
| `figures/` | Hình cho bài báo và bảo vệ: ROC, PR, reliability diagram, sơ đồ kiến trúc, sơ đồ mô hình. Định dạng PDF vector, kèm PNG |
| (tuỳ chọn) `paper/` | Bản LaTeX nếu nhóm muốn giữ bài báo cùng repo |

Mỗi hình nên có script sinh ra nó trong `scripts/` hoặc notebook trong `notebooks/review/`, ghi tên script ở chú thích file.
